# React Bits components

Copied from the React Bits registry (https://reactbits.dev, `/r/<Name>-TS-CSS.json`), TypeScript + plain CSS variants.
They are vendored source, so edit them here. To update one, re-fetch its registry JSON and diff.

Used on the marketing site:
- Grainient: homepage hero, every page hero (ui/PageHeroBackground), and the "Built for assistants" dark section
- GlassSurface: the condensed top nav pill (components/Header)
- Threads: shared closing CTA (components/ui/CtaSection)
- LogoLoop: integrations strip
- SpotlightCard: security cards
- SpecularButton: every primary button (components/ui/Button). Synced edit: accepts `href` and renders an <a>.
